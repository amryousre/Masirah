# Masirah → Figma

Each `.html` file here is self-contained (fonts, scripts, data inlined) and works offline.

## Import as editable Figma layers
1. In Figma, install the **html.to.design** plugin (Plugins → Browse → "html.to.design").
2. Run it, choose **Import HTML file**, and pick one of these files.
3. Set width to **1440** for desktop screens or **360** for mobile.
4. Each import captures the screen currently shown. To get every screen:
   - open the file in a browser, use the screen switcher at the top, the language switch inside the frame, and the "Show failure state" button,
   - and import each state (the plugin's browser extension can capture the page you are looking at in one click).

## Files
- Masirah Index — map of all files + design notes
- Masirah Foundations — tokens, type test, contrast
- Masirah Components — every component in seven states
- Masirah Phase 1 / Phase 1 Setup — core screening
- Masirah Website — landing and pricing
- Masirah Phase 2 / 3 / 4 — pipeline, commercial, expansion
- Masirah Back Office — internal console (incl. Plans & pricing)
- Masirah Candidate Pages — status, booking, acknowledgement, rejection

## Tips
- Fonts: install IBM Plex Sans Arabic, IBM Plex Sans and IBM Plex Mono locally so Figma keeps the text editable.
- Mobile: open a file in a browser window about 400 px wide (or with devtools device mode at 360 px) before capturing.
